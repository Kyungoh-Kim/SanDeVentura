# SanDeVentura — 유즈케이스 시뮬레이션

> 3가지 실제 사용 시나리오와 정량적 효과를 현실적으로 분석합니다.
> 수치는 국내 등산 통계(한국등산지도 연구소, 소방청 산악 구조 통계)와 앱 성격을 기반으로 합니다.

---

## 유즈케이스 1: "혼자 등산하는 직장인" — 갈림길 불안 해소

### 시나리오 배경

**사용자:** 김지수 (32세, 서울 거주, 회사원)
- 주 1회 북한산, 도봉산 등 수도권 중소 산 등산
- 스마트폰으로 등산 기록하는 습관 있음
- 혼자 산행 시 갈림길에서 자주 불안감 느낌
- 공식 등산 앱(산림청 앱)에 해당 코스 데이터 없거나 부정확한 경우 경험

### 시뮬레이션

```
시나리오: 북한산 숨은벽 코스 첫 단독 산행

10:15 — 앱에서 산 선택 후 기록 시작 (오프라인 동작)
10:47 — 첫 번째 갈림길 도착
        snap-position 호출 → "경로 위" (거리 12m)
        → 불안 없이 오른쪽 경로 선택
11:23 — 세 번째 갈림길 도착 (비공식 샛길)
        snap-position 호출 → "경로 이탈 위험" (거리 63m)
        → 뒤로 돌아 올바른 경로로 복귀
13:40 — 하산 완료, 세션 종료
14:05 — 와이파이 연결 후 세션 업로드 (1개 세션, 약 3,200포인트)
```

### 기존 상황과 비교

| 항목 | 기존 (공식 앱/지도) | SanDeVentura |
|---|---|---|
| 해당 코스 데이터 | 없음 또는 1~2년 전 데이터 | 실제 산행자 경로 축적 |
| 갈림길 실시간 안내 | 불가 | snap-position으로 25m 이내 감지 |
| 단독 산행 불안도 | 높음 (구조 요청 우려) | 경로 이탈 즉시 알림으로 감소 |

### 정량적 효과 (현실적 추정)

**개인 효과:**
- 갈림길 결정 시간: 평균 4~7분 → 1분 이내로 단축 (약 80% 감소)
- 잘못된 경로 진입 후 복귀로 인한 추가 시간: 평균 22분 손실 → 거의 0
- 단독 산행 중 위기감(길 잃음 위험 체감) 빈도: 연 3~5회 → 연 0~1회

**데이터 기여 효과:**
- 1회 산행 = 약 3,000~5,000개 GPS 포인트 기여
- 10회 산행 누적 시: canonical trail 신뢰도 ≥ 0.8 (현실적 임계값)
- 해당 코스 후속 사용자 경로 안내 품질 직접 향상

**소방청 산악 구조 통계 맥락:**
- 2022년 산악 조난 사고 중 약 31%가 "실족 및 길 잃음" (소방청 통계)
- 수도권 중소 산 단독 산행 조난의 70% 이상이 비공식 코스에서 발생
- SanDeVentura가 활성화된 산에서 길 잃음 조난 건수 10~20% 감소 가능 (초기 예측)

## 유즈케이스 2: "등산 동호회 총무" — 단체 산행 데이터 기여자

### 시나리오 배경

**사용자:** 박상호 (48세, 경기도 거주, 중견기업 관리직)
- 30명 규모 직장 등산 동호회 총무
- 월 2회 정기 산행, 비공식 코스 자주 이용
- 앱 활용에 익숙하고 데이터 공유에 적극적
- 동호회 코스 기록을 체계적으로 남기고 싶은 니즈

### 시뮬레이션

```
시나리오: 6개월간 강원도 비공식 코스 정기 산행 (월 2회, 총 12회)

[1~3회차] — 해당 산 canonical trail 아직 없음
    snap-position: "경로 데이터 없음" 반환
    기록만 진행 → 세션 업로드
    백엔드: 3개 세션 누적 → 초기 canonical trail 생성 (신뢰도 0.3)

[4~6회차] — 초기 경로 안내 가능
    snap-position: 기본 안내 시작 (정확도 제한적)
    동호회원 2명도 앱 사용 → 총 9개 세션 누적
    신뢰도: 0.3 → 0.55 상승

[7~12회차] — 안정적 경로 안내
    동호회원 5명 사용 → 총 24개 세션 누적
    신뢰도: 0.55 → 0.82 상승
    갈림길 안내 정확도: 실사용 기준 약 90% 수준
```

### 기존 상황과 비교

| 항목 | 기존 방식 | SanDeVentura |
|---|---|---|
| 비공식 코스 데이터 생성 | 개인 메모 또는 Komoot 업로드 (수동) | 자동 수집 + 자동 경로 추론 |
| 데이터 재사용성 | 개인 기기에 고립 | 전체 사용자 공유 canonical trail |
| 신뢰도 향상 속도 | 불가 | 세션 누적 시 선형 향상 |

### 정량적 효과 (현실적 추정)

**데이터 생산 효과:**
- 6개월 × 동호회 6명 = 24~30개 세션 → 약 90,000~150,000 GPS 포인트 기여
- 강원 비공식 코스 2~3개에 대해 신뢰도 0.8+ canonical trail 생성
- 수동 GPX 파일 편집 대비 데이터 생산 공수: 건당 30분 → 0분 (자동화)

**플랫폼 성장 효과:**
- 동호회 1개(6명 활성)가 6개월 내 코스 3개 커버리지 확보
- 해당 코스 사용자: 연간 500~2,000명 추정 (강원 인기 비공식 코스 기준)
  → 그 중 30%가 앱 사용 시 추가 세션 기여 → 선순환 구조

**비용 절감:**
- 전통적 등산 앱 비공식 코스 데이터 수집 비용: 코스당 현장 실측 + 편집 약 80~200만원
- SanDeVentura 방식: 사용자 기여로 비용 0원, 데이터 갱신도 자동

## 유즈케이스 3: "등산 앱 오퍼레이터(개발자)" — 경로 품질 모니터링

### 시나리오 배경

**사용자:** 최운영 (개발자, SanDeVentura 운영자)
- 앱 출시 후 베타 테스트 기간 (첫 3개월)
- 사용자 5~20명, 산 10개, 세션 50~200개 누적 중
- snap-position 오류 신고 수 확인 필요
- 경로 추론 결과가 실제 코스와 일치하는지 검증 필요

### 시뮬레이션

```
시나리오: 베타 3주차 — 특정 산에서 이탈 알림 오작동 신고 접수

[월요일] 사용자 2명 "경로 위인데 이탈 경고 뜸" 신고
    │
    ▼
[대시보드 Quality 페이지 접속]
    route_quality_inputs 확인:
    - 해당 산 누적 세션: 4개 (임계값 미달)
    - 평균 GPS 정확도: 18m (산림 밀집 구간 — 허용 범위 상단)
    - 거부 포인트 비율: 12% (정상 범위 8% 대비 높음)
    │
    ▼
[Routes 페이지에서 경로 geometry 확인]
    OpenLayers 지도에서 canonical trail 시각화
    → 특정 구간에서 경로가 실제 등산로에서 15m 편차 발견
    │
    ▼
[원인 분석]
    rejected_track_points 테이블 조회:
    rejection_reason: "accuracy > threshold (max: 15m, got: 18–22m)"
    → 해당 구간 수목 밀도 높아 GPS 정확도 저하
    │
    ▼
[대응]
    1. 해당 산 정확도 임계값 완화 (15m → 25m) 조정
    2. recompute-canonical-trails 수동 트리거
    3. 3일 후 canonical trail 재계산 완료
       경로 편차: 15m → 4m로 개선
    │
    ▼
[결과 확인]
    이탈 오경보 신고: 주 4건 → 0건
```

### 기존 상황과 비교

| 항목 | 로그 직접 조회 방식 | SanDeVentura 대시보드 |
|---|---|---|
| 문제 파악 시간 | DB 쿼리 + 로그 분석 약 2~4시간 | 대시보드 진입 후 약 10~20분 |
| 시각적 경로 확인 | GeoJSON 직접 파싱 + QGIS 등 외부 도구 | OpenLayers 지도 즉시 확인 |
| 재추론 트리거 | Edge Function 직접 curl 호출 | 대시보드 버튼 (또는 cron 자동화) |

### 정량적 효과 (현실적 추정)

**운영 효율:**
- 품질 이슈 진단 시간: 2~4시간 → 15~30분 (75~85% 단축)
- 월 발생 이슈 건수 (베타 기간): 8~15건
  → 절약 시간: 월 약 10~30시간의 개발자 공수 절약

**제품 품질 개선 속도:**
- 이슈 발견 → 수정 → 재추론 → 검증 사이클: 기존 5~7일 → 2~3일
- 베타 3개월 내 경로 품질 불량 이슈 해소율: 약 80% (기존 방식 대비 2배 빠름)

**사용자 리텐션 효과:**
- 오경보(false alarm) 빈도 감소: 주 4건 → 0건
  → 앱 신뢰도 하락으로 인한 이탈 방지
- 베타 사용자 30일 리텐션: 오경보 없을 경우 약 60% 유지 (오경보 다발 시 약 35%)
  → 리텐션 25%p 차이 → 20명 베타 유저 기준 5명 추가 유지

## 요약: 3가지 유즈케이스 정량 효과 비교

| 유즈케이스 | 핵심 효과 | 정량 수치 |
|---|---|---|
| 1. 단독 산행 직장인 | 길 잃음 위험 감소 | 갈림길 결정 시간 80% 단축, 조난 위험 체감 연 3→0회 |
| 2. 동호회 총무 | 비공식 경로 자동 데이터화 | 6개월 150,000 포인트 기여, 코스당 수집 공수 30분→0분 |
| 3. 운영자(개발자) | 품질 모니터링 + 빠른 대응 | 진단 시간 80% 단축, 베타 리텐션 25%p 개선 |
