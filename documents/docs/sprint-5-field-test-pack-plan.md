# Sprint 5 Field Test Pack Plan

**Goal**: package the final pre-beta validation work so a real-device field test
can be executed without inventing steps during the hike.

## Specific Steps

1. Create a field-test checklist for recording, upload, route recompute,
   guidance retrieval, and snap-position.
2. Create manual test scenarios for airplane mode, app restart, duplicate
   upload, low-confidence route wording, and fork-position judgments.
3. Add a local replay README that describes how to seed accepted traces and
   verify canonical route output.
4. Add final verification notes that tie sprint 3/4/5 outputs to the MVP
   acceptance criteria.
5. Run the full available local check set after sprint 5 changes.

## Test Scenario I Cannot Perform

Thirty-minute Android field test on a real mountain with weak connectivity:
record in airplane mode, force close and restore, finish, upload on
connectivity, recompute the trail, and check snap guidance at a known fork.
