## Required Evidence Per Mountain

- Route state: `none`, `reference`, or `recommended`.
- Canonical trail version and confidence when a route exists.
- Session count and accepted/rejected point counts used for recompute.
- Snap-position probes for on-route, caution, and away when a route exists.
- Screenshot or exported result from operator route coverage.

## Non-Local Work

Actual mountain selection, physical field evidence, and hosted staging access
validation must be completed by the beta operator before launch.
